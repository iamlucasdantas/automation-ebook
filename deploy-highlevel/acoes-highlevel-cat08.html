Criar Invoice

Create Invoice
★ Principal
O que esta ação faz

Cria cobrança (invoice) no HighLevel. Dispara envio automático pro cliente com link de pagamento integrado (cartão, PIX, boleto conforme configurado).

Quando usar
Caso
Nova venda
Contrato aprovado → Create Invoice.
Caso
Renovação automática
Data de renovação → nova invoice.
Caso
Cobrança recorrente
Mensalidade → invoice todo dia X.
Configurações principais

Produtos/itens, Valor, Data vencimento, Template de email, Forma de pagamento aceita.

Caso
Venda rápida
Lead quente → checkout direto.
Caso
Cobrança adicional
Serviço extra → link do valor exato.

Valor, Produto (opcional), Descrição.

⚠ Financeiro
O que esta ação faz

Processa reembolso (total ou parcial) de pagamento. Integra com Stripe/gateway configurado. ATENÇÃO: movimento financeiro real.

Política de garantia
7 dias de garantia → auto-refund se solicitar.

Parcial
Parte do serviço não entregue → refund parcial.
Configurações principais

Valor (total ou parcial), Motivo, Gateway.

Cancelar Subscription

Cancel Subscription
O que esta ação faz

Cancela assinatura recorrente do cliente. Para cobranças futuras mas mantém histórico. Diferente de Delete — é graceful.

Quando usar
Caso
Cliente cancelou
Solicitação de cancelamento → cancela subscription.
Caso
Fim do contrato
Contrato 12 meses terminou → auto-cancela.
Caso
Inadimplência
3 cobranças falharam → cancela.
Configurações principais

Sub específica, cancelar imediato ou ao fim do período.
