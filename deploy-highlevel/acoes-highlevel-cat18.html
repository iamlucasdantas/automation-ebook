01
Browse AI

Executar Tarefa

Run Task
PremiumRequer API key própria
O que essa ação faz

Dispara a execução de um robô específico da Browse AI a partir do workflow, passando parâmetros de entrada pra essa execução (ex: uma URL específica, um termo de busca, um filtro). O robô roda do lado da Browse AI e o resultado fica disponível pras próximas etapas.

É a ação companheira do gatilho "Browse AI: Tarefa Concluída" — você pode disparar a tarefa aqui e escutar a conclusão dela em outro workflow, ou simplesmente disparar e seguir em frente sem esperar.

Quando usar na operação
Caso 01
Scraping sob demanda
Lead pede uma cotação → dispara robô que busca o preço atualizado num site de fornecedor.
Caso 02
Verificação de disponibilidade
Novo agendamento → dispara robô que checa disponibilidade num sistema externo sem API pública.
Caso 03
Enriquecimento de lead
Contato criado → dispara robô que extrai dados públicos do perfil da empresa do lead.
Campos principais
Robô
Robot
obrigatório
Dropdown com todos os robôs treinados na sua conta Browse AI conectada. Qual robô essa ação deve executar.
Impacto: Cada robô tem seus próprios parâmetros de entrada — o robô selecionado define o que aparece no campo seguinte.
Parâmetros de Entrada
Input Parameters
variáveis
Pares chave/valor passados pro robô na hora de rodar — ex: url = {{contact.website}}. Pode usar merge fields do HighLevel.
Impacto: Sem os parâmetros certos, o robô roda com os valores padrão configurados na Browse AI (se houver) ou falha.

02
Browse AI

Executar Tarefas em Lote

Bulk Run Tasks
PremiumRequer API key própria
O que essa ação faz

Executa o mesmo robô da Browse AI várias vezes de uma vez, cada execução com um conjunto diferente de parâmetros de entrada — por exemplo, rodar o mesmo robô de extração de preço pra uma lista inteira de produtos/URLs, ao invés de disparar "Run Task" um por um.

Mais eficiente que chamar "Executar Tarefa" dentro de um loop quando você já tem a lista completa de inputs no momento do disparo.

Quando usar na operação
Caso 01
Monitoramento de catálogo
Lista de 50 produtos concorrentes → uma chamada em lote extrai o preço de todos de uma vez.
Caso 02
Enriquecimento em massa
Importação de lista de leads → roda o robô de enriquecimento pra todos os perfis importados.
Campos principais
Robô
Robot
obrigatório
Dropdown com os robôs da conta Browse AI conectada — o mesmo robô é usado em todas as execuções do lote.
Impacto: Todas as execuções do lote compartilham a mesma lógica de extração; o que muda é o input de cada uma.
Lista de Inputs em Lote
Bulk Input List
obrigatório
Lista com os parâmetros de entrada de cada execução individual do lote (ex: uma URL por linha).
Impacto: Cada item da lista vira uma execução separada do robô selecionado.
03
Browse AI

Buscar Tarefa

Get Task
PremiumRequer API key própria
O que essa ação faz

Busca o status e o resultado de uma tarefa específica já disparada na Browse AI, usando o ID da tarefa. Útil quando a tarefa foi disparada em outro momento (por exemplo, via "Executar Tarefa" numa etapa anterior, ou até fora do HighLevel) e agora você precisa consultar o resultado.

Quando usar na operação
Caso 01
Consulta depois de um Wait
Dispara a tarefa → Wait de alguns minutos → Get Task pra puxar o resultado já pronto.
Caso 02
Reconsulta manual
Time comercial pede reconsulta de uma extração antiga usando o Task ID salvo em custom value.
Campos principais
ID da Tarefa
Task ID
obrigatório
O identificador único da tarefa retornado quando ela foi criada (por "Run Task" ou "Bulk Run Tasks"). Normalmente vem de uma variável salva em etapa anterior.
Impacto: Sem o ID correto, a busca não encontra a tarefa.
04
Browse AI

Buscar Execução em Lote

Get Bulk Run
PremiumRequer API key própria
O que essa ação faz

Busca o status e os resultados de uma execução em lote (disparada via "Executar Tarefas em Lote") usando o ID do lote. Retorna o progresso e os resultados já concluídos de cada item do lote.

Quando usar na operação
Caso 01
Acompanhamento de lote grande
Lote de 100 URLs disparado de manhã → à tarde, Get Bulk Run consulta quantos já terminaram.
Caso 02
Fechamento de relatório
Quando o lote termina, consulta os resultados completos pra montar um relatório consolidado.
Campos principais
ID do Lote
Bulk Run ID
obrigatório
O identificador único do lote retornado quando ele foi criado por "Bulk Run Tasks". Normalmente vem de uma variável salva na etapa anterior.
Impacto: Sem o ID correto, a busca não encontra o lote.
05
Manus

Criar Tarefa

Create Task
Requer API key própria
O que essa ação faz

Cria uma nova tarefa no agente autônomo Manus a partir de um prompt em linguagem natural — a mesma lógica do gatilho "Manus: Nova Tarefa Criada" só que disparada pelo próprio workflow do HighLevel, ao invés de vir de fora. A Manus processa o prompt de forma assíncrona e multi-etapas.

É o ponto de entrada mais comum da integração: você descreve o que precisa em texto livre (pesquisar, gerar documento, analisar dados) e a Manus decide os passos pra chegar lá.

Quando usar na operação
Caso 01
Pesquisa automática de lead
Novo lead B2B → Create Task pede pra Manus pesquisar a empresa e montar um resumo.
Caso 02
Geração de proposta
Oportunidade avança de estágio → Create Task pede pra Manus rascunhar uma proposta comercial.
Caso 03
Análise de dados sob demanda
Formulário de briefing preenchido → Create Task pede análise dos dados enviados.
Campos principais
Prompt / Instrução
Prompt
obrigatório
A instrução em linguagem natural do que a Manus deve fazer. Aceita merge fields do HighLevel pra personalizar por contato/oportunidade.
Impacto: Quanto mais claro e específico o prompt, mais previsível o resultado da tarefa.
Parâmetros Opcionais
Optional Parameters
opcional
Configurações adicionais da tarefa (quando disponíveis na integração) além do prompt principal.
Impacto: Refina o comportamento sem precisar reescrever o prompt inteiro.

Manus

Buscar Tarefa

Requer API key própria
O que essa ação faz

Busca o status e o resultado atual de uma tarefa da Manus usando o ID da tarefa. Retorna o que já foi processado até o momento — útil pra tarefas longas onde você quer consultar o progresso antes de decidir o próximo passo do workflow.

Quando usar na operação
Caso 01
Consulta pós-espera
Create Task → Wait → Get Task pra puxar o resultado já pronto e seguir o workflow.
Caso 02
Painel de acompanhamento
Time consulta manualmente o status de uma tarefa específica usando o Task ID salvo.
Campos principais
ID da Tarefa
Task ID
obrigatório
O identificador único retornado quando a tarefa foi criada por "Create Task". Normalmente vem de uma variável salva em etapa anterior.
Impacto: Sem o ID correto, a busca não encontra a tarefa.
07
Manus

Atualizar Tarefa

Update Task
Requer API key própria
O que essa ação faz

Atualiza campos de uma tarefa já existente na Manus, identificada pelo Task ID — por exemplo, ajustar instruções ou metadados da tarefa sem precisar criar uma nova do zero.

Quando usar na operação
Caso 01
Correção de escopo
Cliente muda o pedido depois da tarefa criada → Update Task ajusta os campos sem recriar a tarefa.
Caso 02
Adicionar contexto
Nova informação chega depois → Update Task anexa esse contexto à tarefa em andamento.
Campos principais
ID da Tarefa
Task ID
obrigatório
Identifica qual tarefa existente será atualizada.
Impacto: Obrigatório — sem ele a ação não sabe qual tarefa alterar.
Campos a Atualizar
Fields to Update
obrigatório
Os valores/campos da tarefa que devem ser alterados nessa chamada.
Impacto: Só os campos informados são alterados — o resto da tarefa permanece como estava.
08
Manus

Buscar Tarefas

Fetch Tasks
Requer API key própria
O que essa ação faz

Lista várias tarefas da conta Manus conectada de uma vez, ao invés de buscar uma por uma pelo ID — útil pra montar relatórios ou verificar o volume de tarefas em andamento/concluídas.

Quando usar na operação
Caso 01
Relatório de uso
Rotina agendada lista as tarefas do período pra montar um resumo de uso do agente.
Caso 02
Auditoria de pendências
Lista tarefas com um filtro específico pra identificar o que ainda está em andamento.
Campos principais
Filtros de Listagem
List Filters
opcional
Critérios opcionais pra restringir quais tarefas retornam na busca (a doc oficial não detalha as opções exatas de filtro ainda).
Impacto: Sem filtro, retorna o conjunto padrão de tarefas da conta conectada.
09
Manus

Excluir Tarefa

Delete Task
Requer API key própria
O que essa ação faz

Exclui permanentemente uma tarefa da Manus usando o Task ID. Use com cuidado — a ação é destrutiva e não tem "desfazer" do lado da Manus.

Quando usar na operação
Caso 01
Limpeza de tarefas de teste
Workflow de teste cria uma tarefa temporária → Delete Task remove ela ao final do fluxo.
Caso 02
Cancelamento por engano
Tarefa criada com prompt errado → Delete Task remove antes de virar custo desnecessário.
Campos principais
ID da Tarefa
Task ID
obrigatório
Identifica qual tarefa será excluída.
Impacto: Ação destrutiva e definitiva — confirme o ID antes de publicar o workflow.
10
Manus

Continuar Tarefa com Prompt

Continue a Task with a Prompt
Requer API key própria
O que essa ação faz

Envia um novo prompt pra uma tarefa já existente da Manus, continuando a conversa/execução em vez de criar uma tarefa do zero — parecido com mandar mais uma mensagem num chat que já tem contexto acumulado.

Use quando o resultado da tarefa original precisa de um refinamento ou um próximo passo, mantendo todo o contexto que a Manus já processou.

Quando usar na operação
Caso 01
Refinar resultado
Resultado da pesquisa veio genérico → Continue a Task pede "aprofunde no item 3" sem perder o contexto.
Caso 02
Próxima etapa do processo
Tarefa gerou um rascunho → novo prompt pede "agora formate como PDF de uma página".
Campos principais
ID da Tarefa
Task ID
obrigatório
Identifica a tarefa existente que vai receber o novo prompt.
Impacto: Precisa ser uma tarefa ainda ativa/válida na conta Manus.
Novo Prompt
New Prompt
obrigatório
A nova instrução, considerando o contexto já acumulado pela tarefa original.
Impacto: Aceita merge fields do HighLevel, igual ao Prompt de "Create Task".
