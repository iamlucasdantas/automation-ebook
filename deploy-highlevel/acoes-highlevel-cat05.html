Agente de IA

AI Agent
AIPremiumNovo
O que esta ação faz

Automatiza tarefas multi-etapa dentro do workflow usando instruções em linguagem natural. O agente decide quais ferramentas usar, em que ordem e com quais parâmetros — eliminando a necessidade de configurar manualmente cada ação em sequência.

Vem pré-carregado com ferramentas nativas: atualização de oportunidades, criação de contatos, envio de SMS, geração de links únicos e mais. Também pode conectar-se a knowledge bases e MCPs externos. É uma ação Premium com cobrança por execução.

Atualização (20/08/2026): o seletor de Model deixou de ser exclusivo da OpenAI — agora também lista modelos Anthropic (Claude) e Google (Gemini), com uma interface redesenhada pra escolher o provedor, o modelo específico e o nível de raciocínio aplicado.

Quando usar
Caso
Qualificação de leads
Agente analisa formulário → cria oportunidade + envia SMS + adiciona tag — em uma única ação.
Caso
Atendimento a dúvidas
Cliente pergunta via chat → agente busca na knowledge base + responde com contexto correto.
Caso
Onboarding dinâmico
Novo contato → agente decide sequência ideal baseado em dados do contato + histórico.
Configurações principais

Instrução em linguagem natural, ferramentas disponíveis (selecionáveis), knowledge base conectada, modelo de IA, formato de saída (texto ou JSON).

Atualizar Bot de IA e Status

Update Conversation AI Bot and Status
Conversation AINovo
O que esta ação faz

Atribui um bot de Conversation AI específico ao contato e liga/desliga o status dele (Active/Inactive) — por contato, não global. É a peça-chave do handoff humano: atendente assumiu a conversa? Desliga o bot pra ele não atropelar.

Com o Sleep Timer, o bot desligado reativa sozinho depois da duração definida — o atendente resolve, e o bot volta a cobrir madrugada e fim de semana sem ninguém precisar lembrar de religar.

Quando usar
Caso
Handoff pra humano
Cliente pediu "falar com atendente" → bot Inactive + sleep timer 4h.
Caso
Trocar de bot por etapa
Lead virou cliente → sai do bot de vendas, entra o bot de suporte/onboarding.
Caso
Ativar bot só pra quem optou
Tag "Atendimento IA" adicionada → bot Active só pra esse segmento.
Configurações principais

Conversation AI Bot (dropdown com os bots da conta), Bot Status (Active/Inactive) e Sleep Timer — duração pro bot reativar automático depois de desligado.

Mistral AI

Mistral AI: Create Chat Completion / Create Embeddings / Analyze Image
AIBetaNovo
O que esta ação faz

Conecta modelos da Mistral (Large, Medium, Small, Ministral, Magistral) direto no workflow, usando a sua própria API key da Mistral — não a conta de IA do HighLevel. Três modos dentro da mesma integração: Create Chat Completion (gera texto — resposta, resumo, reescrita, classificação), Create Embeddings (vetores pra busca semântica) e Analyze Image (visão computacional sobre imagem anexada).

A saída fica disponível como variável de workflow pra qualquer etapa seguinte — Send SMS, Send Email, Internal Notification, Update Contact Field ou lógica condicional. Ação em Beta: modelos, campos e comportamento ainda podem mudar.

Quando usar
Caso
Responder no idioma do contato
Create Chat Completion gera a resposta já no idioma detectado da mensagem recebida.
Caso
Extrair dados de recibo
Contato anexa foto da nota fiscal → Analyze Image extrai valor, data e fornecedor.
Caso
Busca semântica na base de conhecimento
Create Embeddings vetoriza a pergunta do contato pra achar o artigo mais relevante.
Configurações principais

Connect Mistral (cola a API key gerada em console.mistral.ai), Action Type (Create Chat Completion / Create Embeddings / Analyze Image), System Prompt, Prompt, Model e Output Variable.

OpenRouter

OpenRouter: Generate Response
AINovo
O que esta ação faz

Conecta o workflow a mais de 300 modelos de IA através do OpenRouter — um gateway único pra modelos da OpenAI, Anthropic (Claude), Google (Gemini), Perplexity e dezenas de outros provedores, usando a sua própria API key do OpenRouter (não a conta de IA do HighLevel). Você escolhe o modelo pelo equilíbrio de qualidade, velocidade, criatividade e custo que precisa pra cada caso.

O prompt enviado ao modelo aceita variáveis dinâmicas do workflow (dados do contato, respostas de passos anteriores). A resposta gerada fica disponível como Output Variable pra qualquer etapa seguinte — Send SMS, Send Email, Internal Notification, Update Contact Field ou lógica condicional.

Quando usar
Caso
Modelo com busca em tempo real
Perplexity via OpenRouter responde pergunta do lead citando informação atualizada da web — modelo que a conta de IA nativa do HighLevel não oferece.
Caso
Rotear por custo
Usa um modelo mais barato pra triagem simples e reserva um modelo mais caro/potente só pra casos complexos, tudo dentro do mesmo workflow.
Caso
Comparar provedores sem trocar de ferramenta
Testa Claude, GPT e Gemini na mesma automação só trocando o campo Model — sem reescrever o resto do workflow.
Configurações principais

Connect OpenRouter (cola a API key gerada em openrouter.ai/keys), Model (obrigatório — 300+ modelos disponíveis), System Prompt (opcional), Prompt (obrigatório, aceita merge fields/variáveis do workflow) e Output Variable.
