01
Tarefas

Criar Tarefa

Create Task
LC PremiumTodoistCriação
O que essa ação faz

Cria uma nova tarefa em um projeto Todoist conectado à sua subconta HighLevel, usando dados do contato ou da oportunidade em contexto no workflow. Você define conteúdo (nome da tarefa), descrição, projeto de destino, data de vencimento, prioridade (P1 a P4) e labels.

É a ação mais usada da categoria — a ponte principal entre um evento no CRM e uma tarefa acionável pro time operacional no Todoist.

Quando usar na operação
Caso 01
Handoff pós-venda
Oportunidade "Ganho" → cria tarefa "Kickoff: {{contact.full_name}}" no projeto "Implementação Clientes", prioridade P1.
Caso 02
Follow-up de proposta
Proposta enviada sem resposta em 3 dias → cria tarefa "Follow-up: {{opportunity.name}}" pro closer responsável.
Caso 03
Checklist de conteúdo
Novo cliente → cria tarefa "Brief inicial" no projeto de produção, com label "Onboarding".

02
Tarefas

Atualizar Tarefa

Update Task
LC PremiumTodoist
O que essa ação faz

Atualiza campos de uma tarefa já existente no Todoist — conteúdo, descrição, data de vencimento, prioridade ou labels. A tarefa é identificada pelo Task ID, normalmente obtido de uma ação anterior no workflow (ex: "Criar Tarefa" ou "Buscar Tarefa").

Campos deixados em branco mantêm o valor que a tarefa já tinha no Todoist.

Quando usar na operação
Caso 01
Reagendamento
Cliente pede prazo maior → atualiza a data de vencimento da tarefa correspondente.
Caso 02
Repriorização
Oportunidade vira "Urgente" → atualiza a prioridade da tarefa vinculada pra P1.
Campos principais
Task ID
Task ID
obrigatório
Identificador da tarefa a atualizar. Use a variável retornada por "Criar Tarefa" ou "Buscar Tarefa".
Impacto: Sem um Task ID válido, a ação falha silenciosamente.
Campos a atualizar
Content / Due Date / Priority / Labels
opcional
Qualquer combinação de conteúdo, descrição, data de vencimento, prioridade e labels.
Dica: Preencha só os campos que precisam mudar.
03
Tarefas

Concluir Tarefa

Complete Task
LC PremiumTodoist
O que essa ação faz

Marca uma tarefa existente como concluída no Todoist, sem precisar abrir o app. Usa o Task ID pra localizar a tarefa exata a ser fechada.

Quando usar na operação
Caso 01
Fechamento automático
Etapa concluída no HighLevel → marca a tarefa correspondente como concluída no Todoist, mantendo as duas ferramentas sincronizadas.
Caso 02
Cancelamento de follow-up
Cliente respondeu → conclui automaticamente a tarefa "Follow-up pendente".
Campos principais
Task ID
Task ID
obrigatório
Identificador da tarefa a marcar como concluída.
Impacto: Tarefas já concluídas retornam sucesso sem efeito adicional (idempotente).
04
Tarefas

Comentar na Tarefa

Add Task Comment
LC PremiumTodoist
O que essa ação faz

Adiciona um comentário a uma tarefa existente no Todoist — útil pra registrar contexto adicional sem precisar editar o conteúdo da tarefa em si.

Quando usar na operação
Caso 01
Contexto automático
Nova mensagem do cliente relacionada à entrega → adiciona como comentário na tarefa correspondente.
Caso 02
Log de automação
Toda vez que o workflow toca a tarefa, registra um comentário com timestamp pra auditoria.
Campos principais
Task ID
Task ID
obrigatório
Identificador da tarefa que vai receber o comentário.
Impacto: Obrigatório — sem ID válido, o comentário não é publicado.
Comentário
Comment
obrigatório
Texto do comentário. Aceita variáveis do workflow — ex: {{contact.full_name}} respondeu no WhatsApp.
Dica: Use variáveis pra manter contexto rastreável sem precisar entrar no CRM.
05
Projetos

Comentar no Projeto

Add Project Comment
LC PremiumTodoist
O que essa ação faz

Adiciona um comentário no nível do projeto (não em uma tarefa específica) — aparece na aba de comentários do projeto no Todoist, visível pra todos os colaboradores.

Quando usar na operação
Caso 01
Atualização de status
Marco do projeto atingido → posta comentário resumindo o progresso pra quem acompanha o projeto.
Caso 02
Aviso geral
Mudança de prazo do projeto → comentário avisando a equipe toda.
Campos principais
Project ID
Project ID
obrigatório
Identificador do projeto que vai receber o comentário.
Impacto: Obrigatório — combine com "Buscar Projeto" se você só tem o nome.
Comentário
Comment
obrigatório
Texto do comentário a publicar no projeto.
Dica: Ótimo pra registrar marcos automaticamente sem depender de alguém lembrar de comentar manualmente.
06
Projetos

Criar Projeto

Create Project
LC PremiumTodoistCriação
O que essa ação faz

Cria um novo projeto no Todoist automaticamente — por exemplo, um projeto dedicado por cliente novo. Você define o nome, a cor de identificação e, opcionalmente, um projeto pai (pra organizar como subprojeto de uma estrutura maior, como "Clientes Ativos").

Costuma abrir a esteira: assim que o projeto é criado, o ID retornado alimenta ações seguintes como "Criar Tarefa" ou "Convidar Usuário" pra montar toda a estrutura inicial de uma vez.

Quando usar na operação
Caso 01
Onboarding de cliente
Oportunidade "Ganho" → cria projeto "Cliente: {{contact.company_name}}" no Todoist.
Caso 02
Campanha nova
Início de campanha → cria projeto dedicado pra organizar as tarefas de execução.
Caso 03
Padronização de estrutura
Todo projeto novo nasce dentro do projeto pai "Clientes Ativos", com cor definida por segmento.

07
Tarefas · Organização

Mover Tarefa para Seção

Move Task to Section
LC PremiumTodoist
O que essa ação faz

Move uma tarefa existente para uma seção específica dentro do mesmo projeto Todoist — útil pra projetos organizados em fases, tipo um kanban (ex: "A Fazer", "Em Andamento", "Revisão", "Concluído").

Quando usar na operação
Caso 01
Kanban automático
Etapa do pipeline HighLevel avança → move a tarefa correspondente pra seção "Em Andamento" no Todoist.
Caso 02
Fila de revisão
Tarefa marcada como pronta → move automaticamente pra seção "Revisão do Cliente".
Campos principais
Task ID
Task ID
obrigatório
Identificador da tarefa a mover.
Impacto: A tarefa precisa pertencer ao mesmo projeto que contém a seção de destino.
Seção de Destino
Target Section
obrigatório
Dropdown com as seções existentes no projeto da tarefa.
Impacto: Se a seção não existir mais no projeto, a ação falha.
08
Tarefas · Organização

Buscar Tarefa

Find Task
LC PremiumTodoistLookup
O que essa ação faz

Busca uma tarefa no Todoist com base em critérios de filtro (projeto, conteúdo, label, prazo). Retorna os dados encontrados — incluindo o Task ID — como variáveis pras ações seguintes do workflow.

Quando usar na operação
Caso 01
Verificação prévia
Antes de comentar ou atualizar → busca a tarefa pelo nome pra confirmar que ela existe.
Caso 02
Roteamento condicional
Busca tarefa vencida → se encontrar, dispara escalonamento; se não encontrar, segue o fluxo normal.
Campos principais
Projeto
Project
opcional
Escopa a busca a um projeto específico, ao invés de varrer a conta inteira.
Impacto: Recomendado pra evitar falsos positivos em contas com muitos projetos.
Filtro de Busca
Search Filter
obrigatório
Texto, label ou prazo usado como critério de busca — ex: "Kickoff: {{contact.full_name}}".
Resultado: Retorna a primeira tarefa encontrada com os dados disponíveis como variáveis.
09
Projetos · Busca

Buscar Projeto

Find Project
LC PremiumTodoistLookup
O que essa ação faz

Busca um projeto no Todoist pelo nome (ou parte dele). Retorna o Project ID e os dados do projeto como variáveis, úteis pra encadear com outras ações Todoist que exigem um Project ID — como "Criar Tarefa" ou "Comentar no Projeto".

Quando usar na operação
Caso 01
Evitar duplicidade
Antes de criar um projeto novo → busca se já existe um projeto com esse nome pro cliente.
Caso 02
Encadeamento
Busca o projeto do cliente → usa o ID retornado pra criar a tarefa de kickoff dentro dele.
Campos principais
Nome do Projeto
Project Name
obrigatório
Texto (ou variável) usado pra buscar o projeto pelo nome — ex: {{contact.company_name}}.
Resultado: Retorna o Project ID disponível como variável pras ações seguintes.
10
Usuários & Colaboradores

Buscar Usuário

Find User
LC PremiumTodoistLookup
O que essa ação faz

Busca um colaborador (usuário) do Todoist pelo email. Retorna o ID do usuário, útil pra atribuir tarefas ou confirmar acesso antes de convidar alguém novamente pra um projeto.

Quando usar na operação
Caso 01
Atribuição dinâmica
Busca o usuário responsável pelo cliente → usa o ID retornado pra atribuir a tarefa criada em seguida.
Caso 02
Validação antes de convidar
Confirma que o colaborador já existe na conta Todoist antes de disparar um convite duplicado.
Campos principais
Email do Usuário
User Email
obrigatório
Email usado pra localizar o colaborador na conta Todoist conectada.
Resultado: Retorna nome e ID do usuário como variáveis, caso encontrado.

Usuários & Colaboradores

Obter Colaboradores

Get Collaborators
LC PremiumTodoistLookup
O que essa ação faz

Lista todos os colaboradores com acesso a um projeto Todoist específico. Retorna nomes, emails e IDs como uma lista de variáveis — útil pra rodar lógica condicional ou notificar todo mundo envolvido no projeto de uma vez.

Combina bem com "Internal Notification" ou "If/Else" logo em seguida, já que devolve uma lista (não um único valor) que o workflow pode iterar.

Quando usar na operação
Caso 01
Notificação em massa
Marco do projeto atingido → obtém colaboradores → envia notificação interna pra cada um.
Caso 02
Auditoria de acesso
Verificação periódica de quem tem acesso a projetos de clientes sensíveis.
Caso 03
Handoff de equipe
Projeto muda de fase → obtém colaboradores atuais antes de adicionar o próximo responsável.

Usuários & Colaboradores

Convidar Usuário

Invite User
LC PremiumTodoist
O que essa ação faz

Convida um novo colaborador pra um projeto Todoist específico, usando o email dele. O convidado recebe um email do Todoist pra aceitar o acesso ao projeto.

Quando usar na operação
Caso 01
Onboarding de cliente
Cliente aprovado → convida o contato principal pra colaborar no projeto Todoist compartilhado.
Caso 02
Expansão de equipe
Novo membro entra no time → convidado automaticamente pros projetos ativos relevantes.
Campos principais
Email do Convidado
Invitee Email
obrigatório
Email de quem vai receber o convite pro projeto.
Impacto: Obrigatório. O convidado precisa aceitar antes de aparecer como colaborador.
Projeto
Project
obrigatório
Projeto ao qual o convidado terá acesso.
Dica: Combine com "Buscar Projeto" se você só tem o nome do projeto do cliente.
