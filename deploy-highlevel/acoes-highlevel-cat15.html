01
Custom Objects

Criar Registro Associado

Create Associated Record
Custom Objects
O que esta ação faz

Cria um novo registro de objeto personalizado e o associa automaticamente ao contato (ou empresa) que acionou o workflow. Ideal pra criar entidades vinculadas ao contato — contrato, projeto, proposta, imóvel — sem intervenção manual.

Use variáveis do contato pra preencher campos do registro automaticamente no momento da criação.

Quando usar
Caso 01
Abrir contrato
Contato assinou proposta → criar Registro de Contrato associado, com campos Nome, Valor e Data preenchidos automaticamente.
Caso 02
Criar projeto
Cliente fez onboarding → criar Registro de Projeto com Status = "Iniciado" e Responsável = usuário atribuído.
Caso 03
Registrar venda
Pagamento confirmado → criar Registro de Venda com produto, valor e data vinculados ao contato.
Configurações principais

Selecione o tipo de objeto (ex: Contrato, Projeto), defina o nome do registro e mapeie os campos do objeto com valores estáticos ou variáveis do contato ({{contact.first_name}}, {{contact.phone}}, etc.).

02
Custom Objects

Encontrar Registro

Find Custom Object Record
LookupCustom Objects
O que esta ação faz

Busca um registro existente de objeto personalizado com base em critérios de campo — ID, nome, status, ou qualquer campo customizado. Quando encontrado, torna os dados do registro disponíveis como variáveis no workflow.

É o "SELECT" do mundo de Custom Objects no HighLevel — use pra recuperar dados de um registro antes de atualizá-lo ou tomar decisões baseadas nele.

Quando usar
Caso 01
Verificar contrato ativo
Antes de criar novo contrato → buscar se já existe um ativo para o contato e usar condição pra evitar duplicatas.
Caso 02
Recuperar dados do projeto
Contato enviou formulário → buscar projeto associado → usar {{object.nome_projeto}} na mensagem de resposta.
Caso 03
Validar imóvel
Lead chegou com código do imóvel → buscar registro → enviar detalhes do imóvel no WhatsApp automaticamente.

03
Custom Objects

Encontrar Empresa

Find Company
LookupEmpresas
O que esta ação faz

Busca um registro de Empresa (Company) no HighLevel com base em critérios como nome, domínio de email, telefone ou campos customizados. Torna os dados da empresa disponíveis como variáveis no workflow.

Essencial pra operações B2B — permita que o workflow "saiba" com qual empresa o contato está associado antes de tomar ações personalizadas por conta ou segmento.

Quando usar
Caso 01
Personalizar por conta
Novo contato chegou → buscar empresa pelo domínio de email → usar {{company.name}} e {{company.plan}} na mensagem de onboarding.
Caso 02
Verificar plano da empresa
Contato abriu ticket → buscar empresa → verificar campo "Plano" → rotear pro suporte premium se plano = Enterprise.
Caso 03
Upsell baseado em empresa
Empresa atingiu limite de uso → buscar empresa → notificar SDR com dados de MRR e tamanho do time pra pitch de upgrade.

04
Custom Objects

Adicionar ao Workflow

Add Associated Records to Workflow
Custom ObjectsBatch
O que esta ação faz

Pega todos os registros de objeto personalizado associados ao contato atual e os adiciona a outro workflow — ativando automações em lote para cada registro associado.

Exemplo: um contato tem 3 Projetos associados. Essa ação envia cada um dos 3 projetos para um workflow de "Atualização de Status" — sem precisar de loops manuais ou programação.

Quando usar
Caso 01
Renovação em lote
Cliente no momento de renovação → adicionar todos os contratos ativos ao workflow de "Proposta de Renovação" automaticamente.
Caso 02
Notificar por projeto
Mudança de plano → adicionar todos os projetos do cliente ao workflow de "Migração de Plano" com os dados de cada projeto.
Caso 03
Auditoria periódica
Revisão mensal → adicionar todos os imóveis do corretor ao workflow de "Verificação de Status" pra atualização automática.
