Google Forms

Buscar Formulário por ID

Google Forms · Find Form by ID
Integração PremiumGoogle OAuth
O que essa ação faz

Localiza um Google Form específico pelo seu ID único. Retorna os metadados do formulário — título, descrição, campos — para uso nas próximas ações do workflow. Inclui branches Found / Not Found para tratamento condicional.

Quando usar
Caso 01
Validar form antes de processar
Verificar se o form existe antes de tentar buscar respostas — evita erros em workflows críticos.
Caso 02
Buscar metadados dinamicamente
O ID do form vem de um campo custom do contato — busca o form certo para cada segmento.
⚡ Painel de configuração
Form ID pode ser fixo ou dinâmico via → merge field.

Google Forms

Buscar Resposta por ID

Google Forms · Find Response by ID
Integração PremiumResponse ID
O que essa ação faz

Recupera uma resposta específica de um Google Form usando o Form ID e o Response ID. Retorna todos os campos da resposta como variáveis usáveis nas ações seguintes do workflow.

Quando usar
Caso 01
Reprocessar resposta
O Response ID chega via webhook → buscar dados completos da resposta pra popular campos do contato.
Caso 02
Buscar dado específico
Recuperar resposta específica de auditoria para enviar por email ao cliente.
⚡ Painel de configuração
Form ID + Response ID. Ambos podem ser dinâmicos via → {{trigger.response_id}}.

Apify

Executar Ator

Apify · Run Actor
Integração PremiumWeb Scraping
O que essa ação faz

Inicia a execução de um Apify Actor diretamente do workflow. Pode passar inputs dinâmicos — como a URL do site de um lead recém-criado — para personalizar o scraping por contato.

Use em conjunto com a ação Buscar Itens do Dataset após um Wait para processar os resultados.

Quando usar
Caso 01
Enriquecimento automático
Lead criado → executar actor de enriquecimento com o site do lead → aguardar → atualizar campos.
Caso 02
Prospecção outbound
Executar Google Maps Scraper com cidade/nicho → resultados viram novos contatos no CRM.
⚡ Painel de configuração
Selecione o Actor → configure os inputs. → Inputs suportam merge fields dinâmicos.

08
Vapi

Criar Chamada IA

Vapi · Create Call
Integração PremiumAI Voice
O que essa ação faz

Inicia uma chamada de voz com agente IA para o contato do workflow. O agente Vapi faz a ligação outbound, conduz a conversa com o script configurado, e ao encerrar, o resultado fica disponível no HighLevel.

Combine com o gatilho Chamada IA Finalizada (cat13 g4) para criar loops de qualificação automática completos.

Quando usar
Caso 01
Qualificação outbound
Lead preenche form → 1h depois IA liga pra qualificar → resultado volta pro HighLevel automaticamente.
Caso 02
Confirmação de appointment
24h antes da consulta → IA liga pra confirmar presença → confirmado = mantém, recusado = reagenda.

Klaviyo

Criar ou Atualizar Contato

Klaviyo · Create or Update Profile
Integração PremiumEmail Marketing
O que essa ação faz

Sincroniza um contato do HighLevel com um perfil no Klaviyo. Se o perfil já existe (mesmo email), atualiza os campos; se não existe, cria um novo. Mapeia campos custom de ambos os lados.

Quando usar
Caso 01
Pós-compra
Nova compra no HighLevel → cria/atualiza perfil no Klaviyo → entra automaticamente em flow de pós-compra.
Caso 02
Segmentação avançada
Atualizar propriedade "lifecycle_stage" no Klaviyo quando contato muda de estágio no pipeline.
⚡ Painel de configuração
Mapeie campos HighLevel → Klaviyo. → Email é o identificador único do perfil.

Integração PremiumCRM
O que essa ação faz

Quando usar
Caso 01
Equipe usa HubSpot

Caso 02
Relatórios executivos
Dados de pipeline do HL → HubSpot → relatórios de revenue attribution para C-Level.
⚡ Painel de configuração
Mapeie campos HighLevel → HubSpot Properties. → Email é o identificador único.
