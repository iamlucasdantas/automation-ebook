Encontrar Empresa

Find Company
B2B Novo
O que essa ação faz

Busca um registro de Empresa usando critérios de campo. Funciona como "Find Contact" mas para o objeto Company. Retorna o registro encontrado para uso nas etapas seguintes do workflow.

Essencial para cenários B2B onde o workflow começa num Contato mas precisa operar sobre a Empresa associada.

Quando usar na operação
Caso 01
Webhook com domínio
Webhook chega com domínio de email → Find Company pelo domínio → associar contato à empresa encontrada.
Caso 02
ERP envia CNPJ
ERP envia CNPJ → HL encontra empresa pelo campo customizado → atualiza dados e dispara workflow de onboarding.
Campos de configuração
Action Name
Nome da ação
required
Nome descritivo desta ação no workflow.
Impacto: Facilita identificação no canvas quando há múltiplos Find Company.
Search Field
Campo de busca
required
Campo da empresa usado como critério de busca (Name, Email, Phone, custom fields).
Impacto: Determine qual campo identifica unicamente a empresa no seu cenário.
On Match / On No Match
Branches de resultado
condicional
Define o caminho do workflow quando empresa é encontrada ou não encontrada.
Impacto: Crie lógica de fallback — se não encontrar, criar nova empresa ou notificar equipe.

Adicionar Registros ao Workflow

Add Associated Records to Workflow
B2B Novo
O que essa ação faz

Enrola todos os registros associados a uma empresa (ou objeto) em outro workflow. Quando o workflow está rodando no contexto de uma Empresa, essa ação pega todos os Contatos vinculados a ela e os adiciona a um workflow específico.

Automação cross-object real — dispare em Company e atue em todos os Contacts daquela conta.

Quando usar na operação
Caso 01
Onboarding de toda a equipe
Empresa criada → Add Associated Records → enrola todos os contatos dessa empresa no workflow de onboarding de usuários.
Caso 02
Campanha por conta
Empresa upgradeia para Enterprise → enrola todos os contatos no workflow de email de boas-vindas premium.
Campos de configuração
Target Workflow
Workflow de destino
required
Qual workflow receberá os registros associados.
Impacto: O workflow alvo pode ser qualquer workflow ativo na subconta.
Record Type
Tipo de registro
required
Contact, Company ou Custom Object — qual tipo de registro associado será enrolado.
Impacto: Geralmente "Contact" quando o contexto é uma Company.
Association Label
Label de associação
condicional
Filtra por tipo específico de associação quando há múltiplos tipos de relacionamento.
Impacto: Útil para separar "Decisores" de "Usuários" da mesma conta.

Remover Registros do Workflow

Remove Associated Records from Workflow
B2B Novo
O que essa ação faz

Complemento da ação anterior. Remove todos os registros associados a uma empresa de um workflow ativo. Usado para offboarding, cancelamentos ou quando a empresa muda de status e precisa sair de campanhas em andamento.

Quando usar na operação
Caso 01
Churn da conta
Empresa cancela → Remove Associated Records de todos os workflows de nurture → Enrola em workflow de winback.
Caso 02
Downgrade de plano
Empresa faz downgrade → Remover contatos do workflow de onboarding Enterprise → Adicionar ao workflow de plano básico.
Campos de configuração
Target Workflow
Workflow de origem
required
De qual workflow os registros serão removidos.
Impacto: O workflow pode estar ativo — os registros serão retirados imediatamente.
Record Type
Tipo de registro
required
Contact, Company ou Custom Object.
Impacto: Geralmente Contact quando removendo de workflow de email/SMS.

Encontrar Registro de Objeto

Find Object Record
Custom Objects Novo
O que essa ação faz

Para Custom Objects — busca um registro pelo Record ID, External ID ou filtro de campo. Essencial para integrações com ERP/webhook que trazem IDs externos e precisam encontrar o registro correspondente no HighLevel antes de atualizar ou usar seus dados.

A diferença do Find Company: essa ação opera sobre qualquer Custom Object definido na subconta, não só sobre Companies.

Quando usar na operação
Caso 01
ID externo do ERP
Webhook do ERP traz External ID → Find Object Record pelo External ID → atualiza campos do objeto com dados do ERP.
Caso 02
Busca por campo
Número de pedido chega via webhook → Find Object Record pelo campo "Order Number" → retorna objeto Pedido para usar nos próximos steps.
Campos de configuração
Object Type
Tipo de objeto
required
Qual Custom Object será buscado (dropdown com todos os objetos da subconta).
Impacto: Deve corresponder exatamente ao tipo do objeto que você quer buscar.
Search By
Critério de busca
required
Record ID, External ID ou Field Filter.
Impacto: Use External ID para integrações com sistemas que têm seus próprios IDs únicos.
On Multiple Matches
Múltiplos resultados
condicional
O que fazer se mais de um registro for encontrado (usar o primeiro, parar, notificar).
Impacto: Importante para evitar comportamento inesperado quando o campo de busca não é único.
Branch on Found
Branch por resultado
condicional
Divide o workflow em dois caminhos — encontrado e não encontrado.
Impacto: Crie lógica de fallback quando o objeto pode ou não existir.
