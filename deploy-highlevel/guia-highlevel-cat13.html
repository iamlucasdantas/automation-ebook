01
Google Forms

Nova Resposta no Google Forms

Google Forms · New Response
Polling · 5 min Integração Premium Google OAuth
O que esse gatilho faz

Dispara quando uma nova resposta é submetida a um Google Form conectado via OAuth. A integração nativa elimina webhooks manuais — o HighLevel faz polling a cada 5 minutos e dispara o workflow automaticamente.

Conecte via Settings → Integrations → Google Forms. Cada form pode ter seu próprio workflow, permitindo rastrear conversões por origem com precisão.

Quando usar na operação
Caso 01
Formulário de diagnóstico
Resposta recebida → cria contato + tag + dispara sequência de nurturing personalizada.
Caso 02
Pesquisa pós-evento
Nova resposta → score calculado via If/Else → email de follow-up segmentado por NPS.
Caso 03
Formulário de candidatura
Candidatura recebida → notificação interna + criação automática de oportunidade no pipeline.
Como configurar · Fluxo de setup

1. Settings → Integrations → Google Forms → autentique com sua conta Google via OAuth.
2. No gatilho, selecione o Form Name no dropdown — lista todos os formulários da conta.
3. Opcionalmente configure Filter Conditions pra disparar apenas quando certas respostas chegam.
4. Teste submetendo uma resposta no form — o workflow dispara em até 5 minutos.

Filtros disponíveis
Form Name
Form Name
principal
Seleciona o Google Form específico que dispara o workflow.
Impacto: Um workflow por form para rastreabilidade máxima. Formulários diferentes = workflows diferentes.
Filter Conditions

Impacto: Permite criar ramificações sem usar If/Else — o gatilho só dispara quando a condição bate.

02
Typeform

Nova Entrada no Typeform

Typeform · New Entry (Instant)
Tempo real Integração Premium OAuth
O que esse gatilho faz

Dispara instantaneamente quando uma resposta é submetida a um Typeform conectado. Ao contrário do Google Forms (polling), o Typeform usa webhooks nativos configurados automaticamente — disparo em tempo real, sem delay.

Conecte via Settings → Integrations → Typeform usando OAuth. Ideal pra fluxos de qualificação onde velocidade de resposta é crítica.

Quando usar na operação
Caso 01
Qualificação de vendas
Typeform de qualificação → resposta → cria oportunidade no pipeline com score automático.
Caso 02
Feedback de produto
Nova entrada → tag + notificação pro time de produto com respostas mapeadas como campos.
Caso 03
Quiz de segmentação
Resultado do quiz → segmenta contato por produto de interesse + dispara sequência específica.
Filtros disponíveis
Form
Form
principal
O Typeform específico que ativa o workflow. Dropdown lista todos os formulários da conta conectada.
Impacto: Cada Typeform pode ter seu próprio workflow para tracking independente por formulário.

03
Apify

Ator Finalizado

Apify · Actor Run Finished
Polling · 5 min Integração Premium Web Scraping
O que esse gatilho faz

Dispara quando um Apify Actor (bot de web scraping) termina a execução. Permite automatizar coleta de dados externos — LinkedIn, Google Maps, sites de concorrentes — e usar os dados direto no HighLevel sem código.

Conecte via Settings → Integrations → Apify com sua API Key. O HighLevel faz polling a cada 5 minutos verificando runs finalizados.

Quando usar na operação
Caso 01
Scraping do Google Maps
Actor scrapa empresas locais → runs finaliza → cada resultado vira contato com tag de segmentação.
Caso 02
Monitor de concorrente
Mudança detectada no site → actor finaliza → notificação interna + task criada pro time.
Caso 03
Enriquecimento de lead
Lead novo → actor busca dados públicos → run finaliza → campos do contato atualizados automaticamente.
Filtros disponíveis
Actor
Actor
principal

Impacto: Crie um workflow por Actor pra rastrear cada tipo de scraping separadamente.

04
Vapi

Chamada IA Finalizada

Vapi · Call Ended
Tempo real Integração Premium AI Voice
O que esse gatilho faz

Dispara quando uma chamada de voz com IA (feita via Vapi) termina. Vapi é uma plataforma de agentes de voz com IA — o agente faz/recebe ligações automaticamente, e quando a chamada encerra, o HighLevel dispara com os dados completos: transcrição, duração, resultado da conversa.

Perfeito para qualificação automática de leads via voz, sem intervenção humana. Conecte via Settings → Integrations → Vapi com sua API Key.

Quando usar na operação
Caso 01
Qualificação por voz
Agente IA liga pro lead → chamada encerra → resultado salvo no contato + oportunidade criada automaticamente.
Caso 02
Inbound IA
Agente responde ligação recebida → identifica lead → tag adicionada + notificação pro time humano.
Caso 03
Lembrete de appointment
IA confirma presença por telefone → confirmação obtida → status do agendamento atualizado no CRM.
Filtros disponíveis
Phone Number
Phone Number
principal
Número de telefone Vapi conectado ao workflow.
Impacto: Cada número pode ter workflows diferentes para inbound vs outbound.
Call Status
Call Status
opcional
Filtra por resultado: Completed, Failed, No Answer.
Impacto: Crie um workflow pra "No Answer" que reagenda a ligação automaticamente.
